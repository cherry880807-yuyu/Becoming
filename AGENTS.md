# Project Instructions

This is a Unity game project named `Becoming`.

## Collaboration Rules

- Use Traditional Chinese when replying to the project owner unless they ask otherwise.
- Read the existing Unity project structure before making changes.
- Prefer small, focused edits over broad refactors.
- Do not overwrite user changes unless explicitly asked.
- Keep existing naming style, folder structure, and Unity conventions.
- Explain important changes briefly after editing.

## Unity Guidelines

- Main project content lives in `Assets/`.
- Project configuration lives in `ProjectSettings/`.
- Package dependencies live in `Packages/`.
- Avoid editing generated folders such as `Library/`, `Temp/`, `Logs/`, and `UserSettings/` unless specifically requested.
- When editing C# scripts, keep Unity serialization and inspector-facing fields stable unless the task requires changing them.
- Prefer using existing components, prefabs, scenes, and script patterns already present in the project.

## Verification

- When possible, validate changes with available editor logs, tests, or static checks.
- If Unity Editor execution is required but unavailable, state what was not verified.
- Mention any files changed and any follow-up steps the user should perform in Unity.
